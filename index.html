第 13 记
行列式

必记1行列式的性质（5 条）

  • 定义转置：|AT| = |A|（行列互换，值不变）
  • 定义互换：换两行（列）变号 ⇒ 推论：两行（列）相同，行列式 = 0
  • 公式倍乘：某行（列）公因子 k 可提出（注意：只提一行！）
  • 定义倍加：某行（列）×k 加到另一行（列），行列式不变（化简主力）
  • 公式加和（拆分）：某行（列）是两数之和 ⇒ 拆成两个行列式之和

必记2展开定理 ＋ 必记3 代数余子式线性和

公式按行展开：Dn = ai1Ai1 + ai2Ai2 + … + ainAin；异行相乘 = 0：ai1Aj1 + … + ainAjn = 0（i≠j）
对照线性和 k1Ai1 + k2Ai2 + … + knAin ＝ 把原行列式第 i 行换成 k₁…kₙ 的新行列式（高频重点！）

必记4特殊行列式计算（4 类题型）

定义① 行（列）加和相等 ② 爪型行列式 ③ 点斜行列式（按点的位置展开）④ 范德蒙：Dn = Πi>j≥1(xi − xj)（从 0 次方开始，理解算法不死背）

必记5抽象型行列式（必记！太重要）

运算结论易混点
|AT|= |A|转置不变
|AB|= |A||B|乘法可拆
|kA|= kn|A|n 阶方阵每行都提 k，共 n 个
|A−1|= 1/|A|前提：A 可逆
|A*|= |A|n−1（n≥2）指数是 n−1 不是 n
拉普拉斯（主对角分块）|A O; O B| = |A C; O B| = |A O; C B| = |A||B|主对角直接乘
拉普拉斯（副对角分块）|O A; B O| = |C A; B O| = |O A; B C| = (−1)mn|A||B|副对角带符号 (−1)mn
⚠ |A B; C D| ≠ |A||D| − |B||C|（即使 A,B,C,D 同阶也不行）　⚠ |A + B| ≠ |A| + |B|　⚠ 已知 Aij = ±aij ⇒ A* = ±AT
第 14 记
矩阵运算

必记1伴随矩阵 A*

定义A* = (Aji)：代数余子式转置排列（Aij 放在第 j 行 i 列）
公式万能公式（见到伴随的第一定势）：AA* = A*A = |A|E
公式秩公式：r(A*) = n（r(A)=n）；1（r(A)=n−1）；0（r(A)<n−1）
若 |A| = 0 则 AA* = A*A = O ⇒ ① r(A) + r(A*) ≤ n；② A 的列向量都是 A*x = 0 的解，A* 的列向量都是 Ax = 0 的解

必记2逆矩阵

定义AB = BA = E ⇔ A 可逆，B = A⁻¹
对照可逆充要链（五等价，贯穿三记）：|A| ≠ 0 ⇔ r(A) = n ⇔ 行（列）向量组线性无关 ⇔ Ax = 0 仅有零解 ⇔ Ax = b 有唯一解
  • 公式(A−1)−1 = A；(kA)−1 = (1/k)A−1；(AB)−1 = B−1A−1；(AT)−1 = (A−1)T；|A−1| = 1/|A|
定义四种求法：① 定义法（凑 AB = E，396 爱考二阶）② 公式法 A−1 = A*/|A|，二阶口诀「主对调、副变号、除以行列式」③ 初等行变换 (A⋮E) → (E⋮A−1) ④ 分块：(B O; O C)−1 = (B−1 O; O C−1)，副对角分块求逆要换位置：(O B; C O)−1 = (O C−1; B−1 O)

必记3三组对照记忆公式（本记核心，最易混！）

对象转置 T伴随 *逆 −1
乘积（都倒序）(AB)T = BTAT(AB)* = B*A*(AB)−1 = B−1A−1
加法(A+B)T = AT+BT(A+B)* ≠ A*+B*(A+B)−1 ≠ A−1+B−1
三符号关系*、T、−1 两两可交换顺序，如 (A*)−1 = (A−1)* = A/|A|
⚠ 口诀：「乘法都倒序，加法只有转置能拆，三符号随便换」

必记4秩为 1 的矩阵 ＋ 必记5 正交矩阵

对照易混符号（α、β 为非零列向量）：αTβ = βTα = (α,β) = tr(αβT) 是一个数；αβT、βαT 是秩为 1 的矩阵
  • 公式r(A) = 1 ⇔ ∃ 非零列向量 α、β 使 A = αβT（对称阵则 A = ααT）
  • 公式n 次幂：An = [tr(A)]n−1·A（十套卷重点）
  • 定义正交矩阵：AAT = ATA = E ⇒ A−1 = AT；列向量均为单位向量且两两正交；|A| = ±1
第 15 记
初等变换与矩阵的秩

必记1初等矩阵与初等变换（NB 表）

定义E 经一次初等变换 ⇒ 初等矩阵：Eij（换 i,j 行）、Ei(k)（第 i 行 ×k）、Eij(k)（第 j 行 ×k 加到第 i 行）。左乘 = 行变换，右乘 = 列变换
对照项EijEi(k)Eij(k)
左乘（行变换）交换 i, j 行第 i 行 ×k第 j 行 ×k ＋ 第 i 行
右乘（列变换）交换 i, j 列第 i 列 ×k第 i 列 ×k ＋ 第 j 列
行列式−1k1
逆矩阵EijEi(1/k)Eij(−k)
转置EijEi(k)Eji(k)（下标对调！）

初等变换的性质（串一串，全等价）

对照行变换 A→B（同型）⇔ 行向量组等价 ⇔ r(A) = r(B) = r(A;B) ⇔ Ax = 0 与 Bx = 0 同解 ⇔ 列向量组有相同线性关系 ⇔ ∃ 可逆 P，PA = B
对照列变换 A→B（同型）⇔ 列向量组等价 ⇔ r(A) = r(B) = r(A,B) ⇔ ATx = 0 与 BTx = 0 同解 ⇔ 行向量组有相同线性关系 ⇔ ∃ 可逆 P，AP = B

必记2矩阵的秩：定义与求法

定义存在 r 阶子式 ≠ 0，且所有 r+1 阶子式全为 0 ⇒ r(A) = r
公式定势：A ≠ O ⇒ r(A) ≥ 1；两行不成比例 ⇒ r(A) ≥ 2。求法：① 初等变换化为行阶梯，数非零行 ② 行列式：|A| ≠ 0 ⇔ r(A) = n（满秩可逆）

跨记对照
三记串起来的 8 条主线（无死角版）

主线1「|A|≠0」贯穿三记的等价大链条

|A| ≠ 0（13记）⇔ A 可逆、A−1 存在（14记）⇔ r(A) = n 满秩（15记）⇔ 行/列向量组线性无关 ⇔ Ax = 0 仅零解 ⇔ Ax = b 唯一解
反向同样成立：|A| = 0 ⇔ r(A) < n ⇔ 不可逆 ⇔ 向量组相关 ⇔ Ax = 0 有非零解

主线2同一个运算，行列式 / 逆 / 伴随 / 秩 结果大不同（总表）

⚠ 记忆钩子：秩最佛系（转置、数乘、乘可逆阵都不动它）；行列式最敏感（数乘变 kⁿ、初等变换变号/倍乘）；乘法都倒序，加法都不能拆。

主线3T / * / −1 三大运算「再来一次 & 互相组合」对照

维度转置 T伴随 *逆 −1
做两次(AT)T = A（还原）(A*)* = |A|n−2A（不还原！）补(A−1)−1 = A（还原）
与幂组合(Am)T = (AT)m—(Am)−1 = (A−1)m
互相交换三符号两两可换序：(AT)−1 = (A−1)T，(A*)T = (AT)*，(A*)−1 = (A−1)* = A/|A|
作用在 E 上ET = EE* = EE−1 = E
⚠ 唯一的"异类"是 (A*)*：T 和 −1 做两次都回到 A，只有伴随做两次冒出因子 |A|n−2。

主线4四类特殊矩阵一张表（可逆 / 正交 / 秩1 / 初等）

矩阵类型定义逆行列式秩
可逆矩阵AB = BA = EA−1 = A*/|A|≠ 0n
正交矩阵AAT = ATA = EA−1 = AT（白送）±1n
秩1矩阵A = αβTn≥2 时必不可逆0（n≥2）1

秩1矩阵是"极端退化"：行列式 = 0、秩 = 1；正交矩阵是"极端优秀"：逆 = 转置、行列式 = ±1、列向量单位正交。

主线5三种初等行变换：对行列式、秩、向量组影响不同！

行变换操作行列式怎么变秩怎么变向量组 / 方程组
交换两行变号（×(−1)）不变行向量组等价；列向量组线性关系不变；Ax = 0 同解
某行 ×k（k≠0）×k不变
倍加（j 行 ×k 加到 i 行）不变不变
⚠ 这就是「化行阶梯」两用的代价：求秩随便变（秩不变）；算行列式要记账——每换一次行补一个负号，每提一次 k 补一个 k。列变换同理（对偶）。

主线6矩阵乘法「三大禁忌」：数的直觉在这里全失效

数的直觉（✗）矩阵的真相（✓）补救 / 替代工具
交换律 ab = baAB ≠ BA（一般）但 |AB| = |BA|、tr(AB) = tr(BA) 补
消去律 ab = ac ⇒ b = cAB = AC ⇏ B = CA 可逆时可消去（左乘 A−1）
ab = 0 ⇒ a = 0 或 b = 0AB = O ⇏ A = O 或 B = O改用秩：r(A) + r(B) ≤ n（15记公式8）
所以第 15 记的秩公式不是孤立的——它们是矩阵乘法"失去三大定律"之后的替代语言。

主线7行变换 ↔ 列变换：结论全部"对偶" ＋ 数与矩阵之辨

对照左乘初等阵 = 行变换；右乘 = 列变换。行变换保列向量的线性关系、方程组 Ax=0 同解；列变换保行向量的线性关系、ATx=0 同解。记一半推另一半即可。
对照符号之辨：αTβ = (α,β) = tr(αβT) 是数（可互换顺序）；αβT 是矩阵（秩1，n 次幂用迹）。|A|、tr(A) 是数，可自由乘进乘出；A、A*、A⁻¹ 是矩阵，乘法受主线6禁忌约束。

主线8做题触发词（定势思维索引）

  • 见 A* → 先写 AA* = A*A = |A|E，再想 |A*| = |A|n−1、r(A*) 三档
  • 见 AB = O → r(A) + r(B) ≤ n，且 B 的列都是 Ax = 0 的解
  • 见 r(A) = 1 → 拆 A = αβT，n 次幂用 An = [tr(A)]n−1A
  • 见 二阶数值逆矩阵 → 「主对调、副变号、除以行列式」直接秒
  • 见 初等变换描述 → 翻译成左/右乘初等矩阵，套 NB 表
  • 见 可逆判定 → 五等价链任选一个最好算的（通常算 |A|）
  • 见 抽象行列式 |A+B| → 不能拆！改写乘积 A + B = A(E + A−1B) 再取行列式 补
  • 见 化阶梯算行列式 → 换行记负号、提 k 记倍数（主线5）
